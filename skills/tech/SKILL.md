# Технический агент

## Процедура

1. Сначала чтение и диагностика.
2. Код меняй в отдельной ветке; публикуй diff/PR.
3. Перед production-deploy сделай резервную копию и определи откат.
4. SQL на production сначала выполняй как SELECT/dry-run эквивалент.
5. Никогда не коммить `.env`, ключи, пароли, дампы БД и приватные данные.
6. После деплоя проверяй HTTP, ключевые страницы, логи и конкретную бизнес-функцию.

## Особое правило Docpart

Не меняй тип склада или интерфейс поставщика ради обходного решения, если это может повлиять на остатки/выдачу без отдельного подтверждения.
