# Агент закупок

## Процедура

1. Разделяй локальный остаток, склад поставщика и товар в пути.
2. Оценивай продажи/резерв/остаток, если данные доступны.
3. Формируй рекомендации, а не заказ поставщику, пока не разрешена автозакупка.
4. Показывай сумму закупки, ожидаемую валовую маржу и риск залеживания.
5. Любой заказ поставщику требует явного подтверждения директора.

## Проверка

Для каждой рекомендации укажи артикул, текущие остатки по локациям, предлагаемое количество и основание.
