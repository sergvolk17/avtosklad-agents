# AutoSklad App — матрица модулей

| Модуль | Источник | Решение для приложения | Статус V1 |
|---|---|---|---|
| Пользователь/заказы | Docpart | единый аккаунт и синхронизация | P0 |
| Прайсы/цены | Docpart | читать через API, не копировать мастер-данные | P0 |
| Остатки | Docpart | читать по складам/поставщикам | P0 |
| Поиск по артикулу | Docpart | адаптировать под мобильный сценарий | P0 |
| Кроссы/аналоги | Docpart | отображать в поиске | P0 |
| Гараж | Docpart + App | расширить историей ТО и сохраненными деталями | P0 |
| YACCO | App + магазин | отдельный бренд-раздел и подбор масла | P0 |
| Корзина/checkout | Docpart | мобильный слой | P0 |
| Доставка | Docpart/integrations | единый расчет + самовывоз/курьер | P0 |
| Оплата | магазин | единый payment layer | P0 |
| Push | App | новый модуль | P0 |
| Loyalty | Docpart + App | бонусы и персональные предложения | P1 |
| B2B | Docpart + App | отдельный кабинет ИП/ООО | P1 |
| Автосервисы | App | новый marketplace/booking модуль | P1 |
| Чат | App/JARVIS | новый единый канал поддержки | P1 |
| CRM | магазин | события приложения передавать в CRM | P1 |
| Marketplace feeds | Docpart | админский контур, не клиентский UI | P2 |
| Честный знак | магазин | приложение использует результат кассового контура | P1 |
| Analytics | App | события + воронка + JARVIS dashboard | P0 |
| AI подбор | JARVIS/App | после стабильного каталога и API | P2 |

## Правило
Если функция уже стабильно реализована в Docpart, приложение не создает второй независимый бизнес-механизм. Оно дает более удобный мобильный интерфейс к существующей логике.

## Уникальные преимущества AutoSklad App
- Гараж + история обслуживания;
- YACCO oil selection;
- повторные покупки расходников;
- автосервисы и запись;
- B2B кабинет;
- JARVIS;
- push;
- единая персонализация по автомобилю.
