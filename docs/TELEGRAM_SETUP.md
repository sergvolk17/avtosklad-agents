# Telegram для директора

Telegram будет основным каналом управления: директор пишет управляющему агенту, получает отчёты и подтверждает действия.

## Безопасная схема

1. Создать отдельного Telegram-бота через BotFather.
2. Токен вводить только локально во время настройки Hermes.
3. Не помещать токен в GitHub, issue, commit, чат или документацию.
4. Включить pairing/allowlist только для аккаунта директора.
5. Не включать режим разрешения всех пользователей.

## Настройка

Native/Windows:

    hermes gateway setup

VPS/Docker:

    docker compose -f deploy/vps/docker-compose.yml run --rm hermes gateway setup

Выбрать Telegram и пройти интерактивную настройку.

## Проверка

После запуска gateway отправить боту `/status`, затем безопасную команду:

    Покажи роли команды АвтоСклада и ничего не меняй.

До подключения SpaceWeb/Docpart бот работает только с безопасными проектными инструментами.
