# Production Runbook

## Перед любым массовым изменением

1. Зафиксировать цель: какие сущности и какие поля меняются.
2. Получить исходный снимок затрагиваемых записей.
3. Сформировать dry-run: число совпавших, пропущенных, конфликтных записей.
4. Убедиться, что запрос не затрагивает лишние поля.
5. Создать резервную копию/экспорт затрагиваемых данных.
6. Получить явное подтверждение оператора.
7. Применить небольшую контрольную партию, если механизм новый.
8. Проверить контрольные артикула/записи.
9. Применить остальное.
10. Записать результат и способ отката.

## YACCO: обновление цены без остатка

Разрешённая цель: изменить только поле финальной цены существующих YACCO-позиций.

Запрещено в той же операции:
- менять quantity/наличие;
- переносить московский остаток в Пыть-Ях;
- создавать отсутствующие товары без отдельного задания;
- удалять старые записи;
- применять +75% к уже финальной цене.

## Аварийное правило

Если после записи контрольное значение не совпадает с dry-run, новые записи не выполнять. Сохранить диагностику и перейти к откату/разбору.
