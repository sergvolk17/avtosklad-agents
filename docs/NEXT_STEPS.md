2. Выполнить `hermes setup` и выбрать модель/провайдер.
3. Запустить `bash scripts/bootstrap.sh` и проверить `hermes doctor`.
4. Подключить Telegram директора.
5. Подключить GitHub в Hermes с минимально нужными правами.
6. Создать отдельный ограниченный SSH-доступ к SpaceWeb: сначала только чтение/логи/копии.
7. Снять схему хранения Docpart для цен/остатков и написать безопасный адаптер.
8. Первый реальный сценарий: YACCO price audit (read-only) → dry-run → контроль 3 артикулов → только затем write.
