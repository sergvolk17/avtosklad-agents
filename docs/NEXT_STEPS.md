# Следующие шаги

1. Создать пустой GitHub-репозиторий `avtosklad-agents` в аккаунте владельца.
2. Залить этот комплект в репозиторий.
3. Выбрать место запуска Hermes: VPS рекомендуется для 24/7; Windows/WSL подходит для пилота.
4. Выполнить `hermes setup` и выбрать модель/провайдер.
5. Подключить Telegram директора.
6. Подключить GitHub с минимально нужными правами.
7. Создать отдельный ограниченный SSH-доступ к SpaceWeb: сначала только чтение/логи/копии.
8. Снять схему хранения Docpart для цен/остатков и написать безопасный адаптер.
9. Первый реальный сценарий: YACCO price audit (read-only) → dry-run → контроль 3 артикулов → только затем write.
10. После стабильной работы добавить ежедневный отчёт и уведомления по заказам.
