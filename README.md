# АвтоСклад Agents

Безопасная агентная платформа для автоматизации АвтоСклада на базе Hermes Agent.

## Команда

- **Manager** — управляющий и координация.
- **Pricing** — прайсы, розница/опт, контроль наценок.
- **Procurement** — закупки, дефицит и пополнение.
- **Tech** — GitHub, сервер, резервные копии и Docpart.
- **Content** — карточки товаров, SEO и новости.
- **Support** — клиентские ответы и сопровождение заказов.

## Безопасность

По умолчанию агенты анализируют и готовят изменения. Запись в production, изменение БД, цен, остатков, заказов, пользователей и файлов сайта требует отдельного подтверждения. Секреты в Git не хранятся.

## Как запускать

Для быстрого пилота на Windows используйте `docs/DEPLOY_WINDOWS.md`.

Для постоянной работы 24/7 используйте отдельный VPS и `docs/DEPLOY_VPS.md`.

После установки Telegram подключается по `docs/TELEGRAM_SETUP.md`.

## YACCO

- Розница = закупочная цена +75%, округление до рубля.
- Опт = закупочная цена +35%, округление до рубля.
- Московский склад поставщика и физический склад Пыть-Яха считаются раздельно.
- Московский остаток нельзя переносить в Пыть-Ях.
- Финальную рассчитанную цену нельзя наценивать повторно.
- Перед массовой записью обязателен dry-run, резервная копия и контрольные позиции.

## Структура

- `AGENTS.md` — общие правила поведения команды.
- `skills/` — роли и рабочие процедуры.
- `deploy/windows/` — Windows-пилот.
- `deploy/vps/` — защищённый Docker-контур 24/7.
- `workspace/` — рабочая область Hermes.
- `data/` — несекретные входные данные.
- `docs/ARCHITECTURE.md` — архитектура.
- `docs/PRODUCTION_RUNBOOK.md` — правила production.

## Этапы

1. Read-only анализ.
2. Controlled write через dry-run и подтверждение.
3. Ограниченная обратимая автоматизация.
4. Автономные отчёты, мониторинг, контент и закупочные рекомендации.
